Comment utiliser un token API

Ajoutez un en-tête Authorization à chaque requête :

Authorization: Bearer <votre-token>

Le token hérite des permissions de votre compte. Il donne accès aux mêmes ressources que votre connexion habituelle.

Sécurité

  • Le token n'est affiché qu'une seule fois à la création — copiez-le immédiatement.
  • Si vous perdez un token, révoquez-le et créez-en un nouveau.
  • Ne partagez jamais un token dans du code versionné ou des emails.
