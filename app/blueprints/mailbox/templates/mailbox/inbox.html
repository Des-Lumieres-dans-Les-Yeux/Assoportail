Comment configurer la connexion Google ?

Configuration Google OAuth2 — étapes

  1. Google Cloud Console — Rendez-vous sur console.cloud.google.com → sélectionnez ou créez un projet.
  2. Activer les APIs — APIs & Services → Bibliothèque → activez Gmail API et Google Drive API.
  3. Créer un identifiant OAuth 2.0 — APIs & Services → Identifiants → Créer des identifiants → ID client OAuth → type Application Web.
  4. URI de redirection autorisée — ajoutez exactement : https://votre-domaine.com/mailbox/oauth/callback
  5. Télécharger le JSON — cliquez sur l'icône ↓ à côté de l'identifiant créé. Le fichier s'appelle client_secret_…json.
  6. Importer ici ↓ — uploadez le fichier via le formulaire ci-dessous. Un seul fichier couvre la boîte de réception, l'envoi de mailings et Google Drive.
  7. Renseigner ENCRYPTION_KEYS dans le .env (si ce n'est pas déjà fait) : 
    ENCRYPTION_KEYS=<clé Fernet>  # python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
