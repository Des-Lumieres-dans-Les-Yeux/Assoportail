Comment configurer

Facebook + Instagram
  1. Cliquez « Connecter Facebook » ci-dessous
  2. Autorisez l'application sur Facebook
  3. Choisissez la page (si plusieurs)
  4. Instagram est auto-détecté si lié à la page
WordPress
  1. Dans WordPress : Utilisateurs → Profil
  2. Section « Mots de passe d'application »
  3. Créez un mot de passe, copiez-le
  4. Ici : « Ajouter un compte » → WordPress
LinkedIn
  1. Créez une app sur developer.linkedin.com
  2. Ajoutez LINKEDIN_CLIENT_ID et LINKEDIN_CLIENT_SECRET au .env
  3. Ici : « Ajouter un compte » → LinkedIn
Vérifier

Cliquez sur chaque compte pour tester la connexion. Un post n'apparaîtra sur un réseau que si son compte est connecté et actif.

Comptes sociaux

Chaque plateforme connectée ici apparaît comme option lors de la création d'un post.

Facebook + Instagram

  • Un seul clic « Connecter Facebook » suffit pour les deux.
  • Instagram doit être un compte professionnel lié à votre page Facebook dans Meta Business Suite.
  • Si vous gérez plusieurs pages, vous choisirez laquelle connecter.
  • Le token obtenu est permanent (pas d'expiration).

WordPress

  • Utilisez un mot de passe d'application (pas votre mot de passe principal).
  • Générez-le dans WordPress : Utilisateurs → Profil → Mots de passe d'application.
  • Le portail publie via l'API REST WordPress (articles + images).

LinkedIn

  • Nécessite une application LinkedIn Developer avec les scopes w_organization_social.
  • Les clés LINKEDIN_CLIENT_ID et LINKEDIN_CLIENT_SECRET vont dans le fichier .env du serveur.

Tester un compte

Le bouton vérifie que les credentials sont valides en faisant un appel API test.
